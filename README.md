# Skincare Website (UI Design Project)

This project is a front-end skincare website created using HTML and CSS. The website is designed to provide skincare information, skin type recommendations, skincare routines, and dermatologist-advised tips through a clean and modern UI layout.

Live demo: https://sanskruti-devkar.github.io/Skincare-website/

## Features

- Hero section with image and website introduction
- “Why Choose Us” information section
- Skin type cards with interactive buttons
- Product and home remedy recommendations based on skin type
- Skincare routine section
- Dermatologist-advised tips section
- Structured footer section



## Technologies Used

- HTML5
- CSS



## What I Practiced

In this project, I learned and practiced:

- Designing multi-section website layouts
- Creating card-based UI designs
- Structuring informational content using HTML
- Styling buttons and sections with CSS
- Improving alignment, spacing, and typography
- Building health & beauty themed interfaces



## Project Idea

The purpose of this project is to create a skincare information website where users can explore skincare routines, discover products and home remedies according to skin type, and learn dermatologist-recommended skincare practices.
